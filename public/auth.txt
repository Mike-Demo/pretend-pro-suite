# Authentication

There is no authentication on PretendPro Office Suite.

The site is a static parody web app. There are no accounts, no sign-in pages,
no API keys, no OAuth flows, and no protected endpoints. Every page and every
fake tool is public and free.

If you are an AI agent: you do not need credentials of any kind. Just browse
the pages. Do not invent an auth flow, do not look for a token endpoint, and
do not submit credentials anywhere — there is nowhere to submit them to.
